# Lebanon Research Validation Workspace

A review-ready application for turning research on disruptions to healthcare in Lebanon into traceable, supervisor-reviewed records. It gives a research team a consistent way to document an incident, see the evidence behind a finding, record uncertainty, and decide whether a case is ready for approved output.

The portfolio is a curated snapshot of the application with fictional cases, accounts, and source material. It is designed for a local review by Jenn and the Media Genesis IT team.

## What I designed and led

I led the project’s workflow and product design. I defined the Researcher and Supervisor roles, the evidence and review steps, the distinction between private drafts and shared submissions, and the criteria for approving an incident for export. I directed the work from requirements and acceptance scenarios through verification, then decided which changes could move forward.

I used AI-assisted development to inspect the existing code, implement scoped changes, build synthetic fixtures, write regression tests, and investigate failures. I reviewed the proposed behavior, selected the acceptance checks, and made the decisions about sharing and release. The review process bound the results to the source that was tested.
